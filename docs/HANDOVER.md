## 5. 技術構成

- Astro（静的サイト生成）+ Netlify無料プラン。GitHubにプッシュすると自動公開
- 文言はすべて `src/data/site.mjs` に集約。非エンジニアがGitHubの画面で編集できる
- お知らせは `src/content/news/` にMarkdownを1件1ファイルで追加
- Decap CMS（`/admin`）でお知らせを投稿可能（Netlify Identity + Git Gateway）
- 環境変数 `NOINDEX=1` でビルドすると、検索避け版（robots.txt Disallow／noindex／
  sitemap なし）になる。控えサイトはこの設定
- SEO：ページ別title/description、OGP、構造化データ（Organization / WebSite / Person /
  Service / FAQPage / BreadcrumbList）、sitemap.xml、Search Console登録済み
