# 表記ルール

- 作成日：2026年10月13日
- 対象：サイトに出るすべての文章（`src/data/site.mjs`、記事の `.md`、各ページの `.astro`）

このルールは **`npm run build` のたびに機械が検査します**（`scripts/check-style.mjs`）。
違反があるとビルドが止まるため、公開前に必ず気づけます。

---

## 1. 会社・人物の呼び方

| 項目 | 正しい書き方 | 使わない |
| --- | --- | --- |
| 一人称 | **当社** | 弊社 |
| 代表の役職 | **代表社員 辰巳 貴恒** | 代表取締役、社長 |
| 連携する人 | **メンバー**／**専門人材** | スタッフ、社員、従業員 |

### 「スタッフ」「社員」を使わない理由

**社員は代表1名**です。「スタッフ」「社員」と書くと、FAQの「代表1名の会社です」と
矛盾し、実態と違う印象を与えます。

案件ごとに連携する外部の方は、**「メンバー」**または**「専門人材」**と書きます。

> ○ 実務経験と資格を持つメンバーと連携してお引き受けします
> × マーケティング専門スタッフが執筆します

### 「代表」と「代表社員」

- **役職名として示す場所**は「代表社員」（会社概要、プロフィールの肩書き、法務ページ）
- **文章の中で人を指す場合**は「代表」で構いません（例：「代表が直接お話をうかがいます」）

毎回「代表社員が」と書くと読みにくくなるためです。

## 2. 問い合わせまわり

| 項目 | 正しい書き方 |
| --- | --- |
| 返信の目安 | **2営業日以内にご返信します** |
| 相談の時間 | **30分** |
| 相談の費用 | **無料** |
| 打ち合わせ方法 | **オンライン（Google Meet）** |
| 定休日 | **不定休** |

**「できるだけ早く折り返します」は使いません。** ページによって言うことが変わると、
守るべき基準が曖昧になります。

---

## 3. 送り仮名・ひらがな書き

補助動詞はひらがなにします。

| ○ | × |
| --- | --- |
| ください | 下さい |
| いたします | 致します |
| できる・できます | 出来る・出来ます |
| いただく・いただき | 頂く・頂き |
| お問い合わせ | お問合せ、お問合わせ、問い合せ |

「本をください」のように**動詞として使う場合は「下さい」**ですが、
サイト内では登場しないため、一律ひらがなで問題ありません。

---

## 4. 数字・英字

- **半角**を使います（全角の `１２３`、`ＡＢＣ` は使わない）
- 例：30分、2営業日、13年6か月、1200×630

---

## 5. 記号

| 用途 | 記号 |
| --- | --- |
| タイトルの区切り | `｜`（全角縦棒）例：代表｜合同会社To do |
| 並列 | `・` 例：営業・マーケティング |
| 補足 | `（ ）`（全角かっこ） |
| 選択肢の区切り | `／`（全角スラッシュ） |

---

## 6. 書かないこと

方針として決まっているものです。

- 会社の所在地（「全国対応」と書く）
- 電話番号
- 代表以外の方の実名
- 銀行口座
- 料金・金額（「無料相談でお見積り」と書く）
- 取引先の企業名（守秘義務。「大手プライベートエクイティファンド」のような種別で書く）
- 旧メールアドレス `todo.2023.02.23@gmail.com`

---

## 7. ルールを足す・外すとき

`scripts/check-style.mjs` の `RULES` に1行足すだけです。

```js
[/見つけたら困る書き方/g, '正しい書き方', '理由'],
```

### どうしてもその書き方を使いたいとき

その行の末尾に `// style-ok` と書くと、**その行だけ検査を見逃します。**

```js
body: '専門スタッフという語を引用する必要がある場合', // style-ok
```

---

## 8. なぜこのルールがあるか

2026年10月の確認で、次のような食い違いが見つかりました。

- SEOページは「マーケティング専門スタッフ」、FAQは「代表1名の会社です」
- その他のお問い合わせは「できるだけ早く折り返し」、ほかは「2営業日以内」
- プライバシーポリシーだけ「代表社員」、ほかのページは「代表」

**いずれも1ページずつ書いているうちに自然に生じたもの**で、人の目では見つけにくい種類の
間違いです。実際、本文を直した際にページの説明文（検索結果に出る文）の修正が漏れ、
この検査で初めて見つかりました。

ルールと検査をセットにしているのは、そのためです。
