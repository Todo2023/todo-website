# お問い合わせフォーム 設計書（Googleフォーム入力用）

合同会社To do のお問い合わせフォームを、Googleフォームで作るための入力内容です。
上から順に入力すれば完成します。

自動生成したい場合は、同じフォルダの `2026-08-10_create_contact_form.gs` を使ってください。

---

## フォームの基本設定

| 項目 | 入力内容 |
| --- | --- |
| タイトル | `お問い合わせ｜合同会社To do` |
| 説明文 | 下記「説明文」を参照 |
| メールアドレスを収集する | **オフ**（オンにすると回答者にGoogleログインを強制するため） |
| 回答を1回に制限する | オフ |
| 進行状況バーを表示 | オフ |

### 説明文

```
ご相談・お見積りは無料です。「これは頼めるだろうか」という段階でも構いません。
2営業日以内にご返信します。

いただいた内容は、ご連絡およびご提案の目的にのみ使用します。
```

## 質問（全8問）

### Q1. 会社名・団体名

- 形式：**記述式**
- 必須：いいえ
- 説明文：`個人の方は空欄で構いません。`

### Q2. お名前

- 形式：**記述式**
- 必須：**はい**

### Q3. メールアドレス

- 形式：**記述式**
- 必須：**はい**
- 回答の検証：**テキスト → メールアドレス**
  （エラーメッセージ：`メールアドレスの形式でご入力ください。`）

### Q4. ご相談の種類

- 形式：**チェックボックス**（複数選択可）
- 必須：いいえ
- 説明文：`当てはまるものをお選びください。複数可、わからない場合は未選択で構いません。`
- 選択肢：
  1. `アドバイザリー（課題の整理・事業戦略）`
  2. `営業・販促資料の作成`
  3. `ロゴ・名刺等のデザイン`
  4. `秘書・バックオフィス代行`
  5. `AI活用・業務自動化`
  6. `その他・まだ決まっていない`

### Q5. ご相談の概要

- 形式：**段落**
- 必須：**はい**
- 説明文：`一言で構いません。現在おかれている状況や、お困りごとをお書きください。`

### Q6. ご希望の連絡方法

- 形式：**ラジオボタン**（単一選択）
- 必須：いいえ
- 選択肢：
  1. `メール`
  2. `オンライン打ち合わせ（Google Meet 等）`
  3. `どちらでも可`

### Q7. ご検討の時期

- 形式：**ラジオボタン**（単一選択）
- 必須：いいえ
- 選択肢：
  1. `できるだけ早く`
  2. `1〜3か月以内`
  3. `半年以内`
  4. `未定・情報収集の段階`

### Q8. 当社を知ったきっかけ

- 形式：**ラジオボタン**（単一選択）
- 必須：いいえ
- 「その他」の選択肢を追加：**はい**
- 選択肢：
  1. `検索（Google等）`
  2. `Facebook`
  3. `ご紹介`
  4. `以前からの取引`

## 送信後の確認メッセージ

「設定」タブ →「プレゼンテーション」→「確認メッセージ」に入力します。

```
お問い合わせありがとうございます。
内容を確認のうえ、2営業日以内にご返信します。

しばらく経っても返信が届かない場合は、
迷惑メールフォルダをご確認いただくか、
todo.inc.2023.10.13@gmail.com まで直接ご連絡ください。
```

## 完成後のチェックリスト

- [ ] **回答通知をオンにする**
      「回答」タブ → 右上の縦三点メニュー → 「新しい回答についてのメール通知を受け取る」
      ※これを忘れると問い合わせに気づけません。**最重要**
- [ ] 回答先スプレッドシートを作成（「回答」タブ → スプレッドシートのアイコン）
- [ ] 自分でテスト送信し、通知メールが届くことを確認
- [ ] テスト回答をスプレッドシートから削除
- [ ] 「送信」→ 🔗 でURLを取得し、`src/data/site.mjs` の `formUrl` に貼る

## サイトへの反映方法

1. フォーム画面右上の「**送信**」→ リンクのマーク（🔗）を押す
2. 表示されたURL（`https://docs.google.com/forms/...`）をコピー
3. `src/data/site.mjs` を開き、次の行を書き換える

   ```js
   formUrl: null,
   ```
   ↓
   ```js
   formUrl: 'コピーしたURL',
   ```

4. 保存（Commit changes）すると、2〜3分でお問い合わせページにフォームが埋め込み表示されます

短縮URL（`forms.gle/...`）でも動きますが、その場合は埋め込みではなくボタン表示になります。
**埋め込みにしたい場合は `docs.google.com/forms/...` の長いほうのURL**を使ってください。
